# 1.0.8_R — 面板英文界面 + 上下文窗口可配 + 账号表排序（网关 2026.10.28.2_upstream–2026.10.29.1_upstream）

自 v1.0.7_R 以来的全部改进：并入上游 v1.7.7–v1.7.9 共 26 提交。对桌面用户最可感的是**面板英文界面（#107）**、**模型上下文窗口可配置（#106）**和**账号表按列排序（#111）**。

## 🌐 面板 i18n（#107，本批最大新增）

- 零依赖 DOM 边界翻译层（TreeWalker + MutationObserver）：往 `i18n/` 目录放一个 `<语言码>.json` 就出现在顶栏**地球图标语言菜单**里，无需改任何源码；
- 首个语言包 `i18n/en.json`（343 消息 / 68 模式 / 10 片段）；未命中的文本**结构不变式回落中文**（`t(t(x))===t(x)`，不会出现半截翻译卡死）；
- 语言选择记忆在本地（`qd-lang`），切换即整页重载一次；`navigator.language` 自动跟随首访语言；
- 已知边界（如实说明）：fork 桌面的**局域网访问、桌面客户端（托盘/开机自启）**等私有文案暂未进英文包（英文模式下这两块中英混排，不报错、可正常使用）；官方模型名与介绍保持中文源。后续按需要补词条。

## 📏 上下文窗口可配置（#106）

- 面板「模型库」新增**上下文设置**列：官方 `context_config` 各档位（200K/400K/1M…）可单选，写入设置立即生效；
- 请求头 `X-QD-Context: 1M` 单次请求抬窗（chat / responses / anthropic 三端点通用），优先级高于面板；客户端 body 伪造的 `_qd_context` 在入口即被清除；
- 与 fork 的 1M 口径兼容：默认仍取目录值（fork 已把声明 1M 档的模型拉齐 1000000），**只有显式选择才覆盖**。

## 📊 账号表按列排序（#111）

- 版本/账号/状态/积分/请求/总 token/缓存 **七列表头可点**：升序 → 降序 → 恢复默认，三态循环，▲/▼ 指示，状态存本地刷新后保持；
- 账号列**自然序**（`ZZ2` 排在 `ZZ10` 前）；积分列**双口径**：点击、Shift+点击=已用；
- **额度拉取失败的号一律沉底且不随方向翻转**——不会被当成 0 混进「额度用尽」堆里；
- 状态列按「可用→异常→冷却→停用→过期」排；典型用法：点「积分」两下，还有量的号自动到最前。

## 🔧 其它上游改进

- **#105 换模型计费可见**：上游把请求的模型静默回退成 auto 计费时（实测 Kimi-K3 会），usage 行新增 `billed_model`、面板「最近请求」出现红色 **计费→auto** 徽标——「以为在用 Kimi、实际在用 auto」一眼可辨；
- **#102 禁用与签到解耦**：账号禁用不再连带丧失签到资格（新谓词 `checkin_eligible()`，默认行为不变，需要时在设置里开）；
- **#108 额度类 403 快速失败**：单号池下「确定性耗尽」不再被 3 秒短冷却反复撞（fork 保留自己更细的处置：112=模型级付费墙冷却 1h、110=冷却到计费日翻转，账号级语义按 fork 实测取证不变）；
- **#103 DSH credentials 引号修复**：纯数字 API Key 不再被 YAML 解析成整数导致 dsh 插件全灭（智能体一键配置写凭证的稳健性）。
