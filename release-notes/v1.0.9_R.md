# 1.0.9_R — 缓存命中可见 + 计费模型自检 + 英文界面补全（网关 2026.10.31.1_upstream）

自 v1.0.8_R 以来的全部改进：并入上游 v1.7.10（3 提交）。对使用者最直接的三件事 —— **缓存命中率终于读得出来**、**账号计费模型可以当场自检**、**英文界面补上了原生弹窗**。

## 📊 缓存命中不再恒读 0（#112）

- 问题：上游按模型族换缓存字段 —— DeepSeek 发 `prompt_cache_hit_tokens`、Qwen 发 `completion_tokens_details.cached_tokens`，**都不发 OpenAI 标准的 `prompt_tokens_details.cached_tokens`**。按标准协议解析的客户端（含 Zcode、多数 SDK）于是**永远读到 0**，看不到缓存实际省了多少。
- 处置：新增统一归一，把上游各族的缓存数字搬进标准位，**原字段保留**（已按上游形态适配过的客户端不受影响）。
- 影响：prompt cache 命中率统计从此可信——「换个模型问同一个问题为什么这么慢」这类判断不再建立在 0 上。

## 🔎 计费模型自检（#113）

- 面板「模型库」新增**自检**按钮：发一次最小请求，告诉你「你请求的模型」与「上游实际计费的模型」是否一致。
- 背景：上游对某些模型会按客户端身份静默回退成 `auto` 计费（模型清单里标 `minimal_version.vsc=999.999.999` = 该形态未放量）。此前只能靠猜，现在当场可见。
- 配套：billed_model 的 WARN 日志**每小时去重**，不再逐请求刷屏。
- 新增环境变量 `QD_COSY_CLIENTTYPE` / `QD_COSY_UA`（**默认值不变**，仍是 `5` / `undici`）：想把自己 CLI 的客户端身份原样搬过来验证时才需要设。

## 🌐 英文界面补全原生弹窗（PR #114）

- 原生 `alert` / `confirm` / `prompt` 不走 DOM 观察器，英文模式下这些弹窗此前仍是中文 —— 现在一并接线翻译。
- 附带上游新增 `scripts/extract_i18n_keys.py`（从 dashboard 抽取可翻译文案），以及语言包扩容（343 → **608 条消息**，新增 226 条模式 / 26 条片段）。
- 已知边界（如实说明）：fork 桌面的**局域网访问 / 桌面客户端（托盘、开机自启）**等私有文案未进英文包，英文下这两块中英混排（不影响功能）。

## 🧪 fork 侧适配说明

- **一键更新整块维持剔除**（桌面版更新走安装包）：上游语言包带着那批按钮的文案，本 fork 面板没有对应源文本 → 语言包体检会判成「死键」。处置是**不改上游语言包**（保持零 diff，后续同步不冲突），而是在测试侧按原因分类豁免，并加自证守卫（豁免项必须真的在源码里找不到，防清单腐烂）。
- 上游另两条死键是 fork 改写过格式的账号测试 toast 文案（fork 用「✓ 测试通过 · model · 123ms」，上游仍是旧写法），同类处理。
- 签名链路（`qoder_sign.py`）随上游变为可覆盖形态，**默认值不变**；身份与风险识别套件全绿。
