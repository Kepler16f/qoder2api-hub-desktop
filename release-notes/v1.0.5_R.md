# 1.0.5_R — 稳定化批次 + 并入上游 v1.4.2–v1.5.2（网关 2026.10.16.3–2026.10.19.2）

自 v1.0.4_R 以来的网关全部改进一次搭载：核心是**流稳定性**（静默挂死看门狗、预连接心跳补齐、主动令牌续签、错误帧重试语义）与**上游 v1.4.2–v1.5.2 并入**（破坏性变更 #37 已确认接受）。

## 🔧 流稳定性（fork 修复）

- **上游静默看门狗**（2026.10.16.3_re）：HTTP 200 建流后上游零数据超 180 秒（`QD_UPSTREAM_IDLE_MAX` 可调）自动换号重开一次——治大 xhigh 会话被上游静默饿死后客户端反复 `Turn execution failed`。
- **预连接心跳接入 completions 流式**（2026.10.16.4_re）：大上下文请求建连可达 13–26 秒，先发 200+SSE 头、每 5 秒空 delta 心跳——修复经 dsml-proxy 等中间层（8 秒取头超时）被掐流。
- **主动令牌续签**（2026.10.19.1_re）：后台每 60 秒扫描将到期（<300 秒）的账号令牌并刷新，消灭「令牌过期 → 403 风暴」窗口，不再等请求撞 401 才刷。
- **错误帧重试语义对齐 Zcode 白名单**（2026.10.19.1_re）：流内 SSE 错误帧 `type` 改为可重试类型（`upstream_unavailable` / `no_capacity` / `service_unavailable`）——此前这类错误被客户端判定「整回合失败不可重试」（`reason=unknown retryable=false` 的真因）；流内重开改走预连接心跳，消灭静默零字节窗口。
- **模型上下文声明对齐**（2026.10.17.1_re）：1M 档模型 `max_input_tokens` 拉齐 1000000（静态快照 + 加载期规则修正「动态值覆盖回旧值」问题）。

## 📦 下载与安装

| 文件 | 适用 |
|---|---|
| `Qoder2API-Hub-setup-windows-x64.exe` | Windows 10/11 x64（按用户安装，无需管理员） |
| `Qoder2API-Hub-setup-windows-arm64.exe` | Windows on ARM（原生） |
| `Qoder2API-Hub-macos-arm64.dmg` | Apple Silicon Mac |

- macOS：DMG 拖入 Applications，首跑右键打开；仍被拦则 `xattr -cr /Applications/Qoder2API-Hub.app`
- Linux：`sudo dpkg -i qoder2api-hub-linux-*.deb`（依赖系统 WebKit2GTK，dpkg 自动安装）
- 首次看板密码 `admin`，请立即修改
