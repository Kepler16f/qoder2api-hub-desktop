# 1.0.4_R — 信号量机制重写 + 并入上游 v1.4.1（网关 2026.10.16.1–2）

本版聚焦两件事：**重写并发信号量机制**（根治高并发下"全部账号被信号量堵死 → 502"），并入上游 **v1.4.1**（图像输入兼容修复）。

## 🔧 信号量机制重写（2026.10.16.1_re）

- **移除并发分散**：spread（并发分散跳号）与信号量叠加会把账号全部堵死——现在号忙立刻换号扫，全忙才在末位排队
- **信号量泄漏修复**：`_SemGuardResponse` 包装确保流结束必释放；泄漏强制回收 TTL 从 600s 缩到 **120s**
- 效果：agent 型客户端的高并发场景下，"全部账号冷却中"的 502 大幅减少

## 🧲 并入上游（2026.10.16.2_upstream · v1.4.1，issue #33）

- **图像输入兼容修复**：客户端把单个 content part 对象直接当 `content` 字段（非列表）发送时，chat / Responses 的 `str()` 兜底把图像 dict **字符串化成 Python 字面量文本**（模型收到字面文本而非图像），Anthropic 桥单块 dict 被压成空文本吞掉
- 修复：三入口（chat / Responses / Anthropic）的 dict 形态 content 一律按**单元素列表**处理；非 dict 兜底行为不变；+4 回归断言

## 📦 下载与安装

| 文件 | 适用 |
|---|---|
| `Qoder2API-Hub-setup-windows-x64.exe` | Windows 10/11 x64（按用户安装，无需管理员） |
| `Qoder2API-Hub-setup-windows-arm64.exe` | Windows on ARM（原生） |
| `Qoder2API-Hub-macos-arm64.dmg` | Apple Silicon Mac |
| `qoder2api-hub-linux-x64.deb` | 主流发行版 x64（内嵌用系统 WebKit2GTK） |

- Windows：双击安装（SmartScreen 提示时「更多信息 → 仍要运行」）；静默部署 `...setup.exe /VERYSILENT /LANG=chinese`
- macOS：DMG 拖入 Applications，首跑右键打开；仍被拦则 `xattr -cr /Applications/Qoder2API-Hub.app`
- Linux：`sudo dpkg -i qoder2api-hub-linux-*.deb`（依赖系统 WebKit2GTK，dpkg 自动安装）
- 首次看板密码 `admin`，请立即修改
